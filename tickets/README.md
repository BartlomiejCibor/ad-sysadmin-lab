# Zgłoszenia z mojego homelabu

Dokumentuję problemy, które diagnozuję i rozwiązuję w domowym
laboratorium z Windows, Active Directory i GLPI. Są to symulowane
zgłoszenia — nie przedstawiam ich jako doświadczenia komercyjnego, zbieżność osób i nazwisk jest przypadkowa.

## Przypadki

| Zgłoszenie | Obszar | Status |
|---|---|---|
| [01 — Problem z logowaniem do konta domenowego](cases/01-ad-unlock/README.md) | Active Directory, GLPI | W trakcie weryfikacji |

## Jak dokumentuję przypadki

W osobnym pliku opisuję objaw, wykonane testy i ich wyniki,
potwierdzoną przyczynę, podjęte działanie oraz sposób weryfikacji.
Dołączam tylko zrzuty ekranu oczyszczone z danych wrażliwych.

## Statusy

- **Otwarte** — problem jest zgłoszony, diagnoza jeszcze się nie rozpoczęła.
- **W trakcie** — diagnozuję problem lub testuję rozwiązanie.
- **Rozwiązane** — zastosowałem rozwiązanie i potwierdziłem jego skuteczność.
